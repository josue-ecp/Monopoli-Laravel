# Monopoli - Laravel & JavaScript

Proyecto de desarrollo full-stack que adapta las dinámicas y reglas del clásico juego de mesa Monopoli a una aplicación web interactiva.

## 🛠️ Tecnologías
* **PHP / Laravel**
* **Vue.js**
* **HTML / CSS**

## 📌 Características
* Implementación de reglas de juego y lógica de turnos.
* Gestión de recursos, propiedades y transacciones de los jugadores a través de la arquitectura del framework.
